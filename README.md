# Blog App Backend - Module 2

Backend Development for MERN Stack Blog App.

## Features
- Node.js + Express.js Server
- REST APIs
- User Registration API - POST /api/auth/register
- User Login API - POST /api/auth/login
- Create Blog API - POST /api/blogs/create
- Get All Blogs API - GET /api/blogs
- CORS Enabled, Frontend Connected

## Tech Stack
- Node.js
- Express.js
- JavaScript

## How to Run Locally
npm install
npm start
Server runs on http://localhost:5000
